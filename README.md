# Reelbase — Streaming Content Management System

A Laravel application for managing movies, genres, actors, subscriptions, and subscriber watch history.

## Requirements

- PHP 8.2+
- Composer
- Node.js and npm

## Run locally

1. Install PHP and frontend dependencies:

   ```bash
   composer install
   npm install
   ```

2. Create `.env` and generate an application key if needed:

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

3. Configure `.env`. SQLite is configured by default; make sure `database/database.sqlite` exists, or set the `DB_*` values for your database.

4. Create the schema and sample records:

   ```bash
   php artisan migrate --seed
   ```

   If upgrading a local database from the earlier sample schema, back up any data you need first, then run `php artisan migrate:fresh --seed`. This resets the configured database.

5. Build assets and start the app:

   ```bash
   npm run build
   php artisan serve
   ```

   Visit `http://127.0.0.1:8000`.

## Data model

The five project tables are:

1. `movies` — movie titles, release details, and their genre.
2. `genres` — categories that each have many movies.
3. `actors` — cast members, each attached to a movie.
4. `subscriptions` — subscriber identity, plan, price, and status.
5. `watch_histories` — viewing sessions, each linked to a movie and subscriber subscription.

The movie-to-actor relationship is one-to-many so the project stays within the required five tables without adding a cast pivot table. Foreign keys preserve relationships; genres, movies with viewing history, and subscriptions with viewing history cannot be deleted while referenced.

## Features

- Dashboard with movie, subscriber, cast, genre, and watch-history totals.
- Full CRUD for all five project modules.
- Server-side validation, retained form values, success/error notices, and delete confirmations.
- Model factories and sample data generated by `DatabaseSeeder`.
- Bootstrap responsive layout and reusable Blade views.

Run the automated test suite with:

```bash
php artisan test
```
